# sell-in-may 전략 검증 EDA

"5월에 팔고 떠나라(Sell in May and go away)"라는 주식 격언이 실제로 맞는지 데이터로 확인하는 탐색적 데이터 분석(EDA)입니다.

> **가설**: sell-in-may 전략이 주가 변동에 유효할 것이다.
> **결론**: 기각 — 주가는 계절성보다 정치적·자연재해적·경제적·정책적 요인에 더 크게 반응한다.

## 분석 내용

| 순서 | 내용 |
|---|---|
| 1. 전처리 | 코스피 지수, KRX 거래실적, 정책금리 데이터 정리 |
| 2. sell-in-may 소개 | 2008 코스피, 2011 S&P500, 2021 삼성전자, 2022 아모레퍼시픽 사례 |
| 3. 검증 | KRX 연도별 거래량 비교, KOSPI 연도별 반기(11~4월 vs 5~10월) 수익률 비교 |
| 4. 기각 요인 | 정치(미국 대선·친환경 관련주), 자연재해(동일본 대지진·닛케이), 경제(대한항공 인수합병), 특수(코로나·아마존), 거시경제(금리) |
| 5. 복합 요인 | 백신 개발·원유가와 항공사(델타)·원유사(엑슨모빌) 주가, 두바이유–엑슨모빌 회귀분석 |
| 6. 결론 및 제언 | |

## 실행 방법

```bash
git clone <저장소 주소>
cd <저장소 폴더>
pip install -r requirements.txt
jupyter notebook sell_in_may_EDA.ipynb
```

노트북을 위에서부터 차례로 실행하면 됩니다. 주가 데이터는 처음 실행할 때 인터넷에서 내려받아 `data/cache/`에 저장하고, 다음 실행부터는 저장된 파일을 씁니다.

## 폴더 구조

```
.
├── sell_in_may_EDA.ipynb   # 분석 노트북
├── requirements.txt
├── README.md
└── data/
    ├── 코스피_주요주가지수_*.csv
    ├── KRX_상장주식_거래실적_*.csv
    ├── 원유가격_2020_2021.csv
    └── cache/              # 내려받은 주가 (자동 생성)
```

## 데이터 출처

| 데이터 | 기간 | 출처 | 비고 |
|---|---|---|---|
| 코스피 주요 주가지수 (월별) | 2008.01 ~ 2009.04 | [KOSIS 국가통계포털](https://kosis.kr) | `data/`에 포함 |
| KRX 상장주식 거래실적 (월별) | 2019.01 ~ 2023.12 | [KOSIS 국가통계포털](https://kosis.kr) | `data/`에 포함 |
| 국제유가 Dubai·Brent·WTI (월별) | 2020.01 ~ 2021.12 | [한국석유공사 페트로넷](https://www.petronet.co.kr) | `data/`에 포함 |
| 한국은행 기준금리 | 2019 ~ 2023 | [한국은행](https://www.bok.or.kr) | 변경 이력을 노트북에 내장 |
| S&P500, 닛케이225, 아마존, 델타항공, 엑슨모빌, 친환경 에너지 ETF(ICLN), 원유 선물 | 사례별 | [Yahoo Finance](https://finance.yahoo.com) (`yfinance`) | 실행 시 자동 다운로드 |
| KOSPI·KOSDAQ 지수, 삼성전자, 아모레퍼시픽, 대한항공 | 사례별 | `FinanceDataReader` | 실행 시 자동 다운로드 |

CSV 파일이 없으면 노트북이 대체 데이터를 사용합니다. 코스피 지수와 KOSPI·KOSDAQ 거래량은 내려받고, 원유는 Brent·WTI 선물 가격으로 대신합니다.

## 참고

- 한글 그래프를 위해 NanumGothic, 맑은 고딕, AppleGothic, Noto Sans CJK 중 설치된 글꼴을 자동으로 사용합니다.
- 주가 데이터는 내려받는 시점에 따라 수정주가 반영 등으로 값이 조금 달라질 수 있습니다. 같은 결과를 재현하려면 `data/cache/`를 함께 보관하세요.
- 이 분석은 학습용 EDA이며 투자 권유가 아닙니다.
